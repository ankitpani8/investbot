# Regime study 2026-10-18: real-time regime label vs the ex-post regime

> **Survivorship bias.** The universe is *today's* NIFTY50 constituents, back-filled over the whole history. Names that were dropped from the index (usually after underperforming) are missing and names that were added (usually after outperforming) are present before they joined. Absolute returns, and any signal correlated with past winners, are biased upward. Historical constituents are an open data task in docs/BACKLOG.md.

Generated by `python -m scripts.regime_study` (`investbot/evaluation/regime_study.py`). A study only: no threshold, span or weight is changed, and nothing here recommends new constants. Hypotheses, expected signs, horizons, spans and the null seed were pre-registered in the module docstring before the first run.

## Setup

- Universe: 51 active stocks (today's NIFTY50 constituents, see the survivorship caveat above); 62977 daily bars, 2021-10-18 → 2026-10-16.
- Out-of-sample (OOS): 6 walk-forward test blocks of 6 months, 2024-01-01 → 2026-10-16, 690 dates; same settings as the harness (≥ 252 bars after the first date with REGIME on ≥ 10 names, embargo 20 bars). Blocks: `2024-01-01..2024-06-28`, `2024-07-01..2024-12-31`, `2025-01-01..2025-06-30`, `2025-07-01..2025-12-31`, `2026-01-01..2026-06-30`, `2026-07-01..2026-10-16`. Every statistic below uses OOS dates only. Targets near the end of the data are NaN (their window runs past the last bar), so the last block is shorter for H = 60 and FWD_HURST_100.
- Conditioning: `regime.compute_regime` with the production constants (REGIME_WINDOW 100, CONFIDENCE_EMA_SPAN 5); confidence spans 1, 3, 5, 10, 20 via `regime.smooth_confidence` (span 1 = REGIME_CONFIDENCE_RAW).
- Targets (labels, closes t … t+H): FWD_ER, FWD_AC1, FWD_VR5, FWD_VOLX (std of forward returns / REALVOL_250[t]), FWD_MDD at H ∈ {20, 60}; FWD_HURST_100 = DFA Hurst of the next 100 returns (same function and window as the real-time HURST_100).
- Null: every asset's bars shuffled in time (`shuffled_null_bars`, seed 20261018): returns, bar shapes and volumes kept, all serial dependence removed.
- Tests: 35 pre-registered tests (conditional means, rank association, calibration), Newey-West t with lag H, two-sided normal p, Benjamini–Hochberg over all of them. **Supported** = expected sign, BH q < 0.10 and the expected sign in ≥ 70% of the test blocks; **wrong sign** = opposite sign with q < 0.10.
- SCORER_VERSION 4; git `abded89`; runtime 62 s; peak RSS 152 MB.

## Caveats

- **Survivorship bias.** The universe is *today's* NIFTY50 constituents, back-filled over the whole history. Names that were dropped from the index (usually after underperforming) are missing and names that were added (usually after outperforming) are present before they joined. Absolute returns, and any signal correlated with past winners, are biased upward. Historical constituents are an open data task in docs/BACKLOG.md.
- The targets overlap heavily (consecutive dates share H − 1 bars, 99 for FWD_HURST_100), so the effective sample is far smaller than the number of days; the Newey-West t accounts for this only approximately, especially for H = 60 and 100 bars against ~690 OOS dates.
- The null shares one date permutation across assets with the same calendar, so its cross-section still co-moves; only serial dependence is removed.
- FWD_VOLX is normalised by REALVOL_250 and VOL_RATIO = REALVOL_20 / REALVOL_250. The shared denominator alone makes VOL_RATIO vs FWD_VOLX positive across names (see the null IC), and volatility clustering adds to it; REALVOL_20 is also inside REALVOL_250's window, so a high VOL_RATIO inflates the normaliser and lowers FWD_VOLX (see the null chaos − rest difference).
- FWD_HURST_100 has the same DFA small-sample bias as the real-time HURST_100; the trend − range difference is unaffected by a common bias.
