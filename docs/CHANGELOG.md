# Changelog

- 2026-10-17: Migrated Phase 1 and the Phase 2 indicator layer from Google Drive to WSL and git. Added CLAUDE.md, contract tests and the backlog. Fixed the DB path (`.env` was pointing SQLite inside Google Drive).
- 2026-10-17: Fixed the daily smoke-test failure. 50 NULL-close bars on 2026-10-16 (plus 108 zero-volume placeholder bars) poisoned the indicators. Ingestion now validates every price row (`investbot/data/quality.py`), added `python main.py dq [--purge]`, purged 158 bad rows, and added NaN-propagation and ingestion tests.
- 2026-10-17 005-housekeeping: TATAMOTORS.NS → TMPV.NS (old row deactivated, not deleted), removed duplicate smoke script, pct_change(fill_method=None), FutureWarning is an error in pytest, seed no longer mutates TAX_REGIMES
- 2026-10-17 000-ingest-refresh-window: price ingestion upserts a trailing window (last 5 daily sessions, last 2 intraday trading days), skips today's daily bar before 16:00 IST and the forming 15m candle, never overwrites a good row with a rejected one, and logs inserted/updated/rejected per asset.
- 2026-10-17 010-candle-patterns: added `candle_patterns.py`: all 61 TA-Lib CDL* patterns as raw `CDL_*` and normalised `CDLN_*` columns plus `CDL_BULL_COUNT`/`CDL_BEAR_COUNT`/`CDL_NET_SCORE` (warmup NaN, no-lookahead tests). Not wired into `add_all_indicators`
- 2026-10-17 030-regime: added `regime.py`: rolling HURST_100/250 (DFA-1), LYAP_100/250 (Rosenstein, m=3, lag=1), REALVOL_20/250, VOL_RATIO, REGIME_SCORE_*, REGIME (0 range / 1 trend / 2 chaotic) and a continuous REGIME_CONFIDENCE. Thresholds calibrated on NIFTY50 daily; 50 assets × 1234 bars in ~28 s. Not wired into `add_all_indicators`
- 2026-10-17 020-support-resistance: added `support_resistance.py` (swing pivots emitted only at the confirmation bar, pivot-clustered S/R levels with touch/recency strength, rolling 70% volume profile POC/VAH/VAL/POS, Fibonacci retracements of the latest confirmed swing). 25 columns, truncation-invariance tests over all of them, ~0.3 s per 1500-row asset.
- 2026-10-17 040-multi-timeframe: added `multi_timeframe.py`: `resample_ohlcv` (NSE-session-anchored bins labelled by close time, partial 15:30 bar), `align_higher_timeframe` (only closed HTF bars; daily values from the previous session), `mtf_alignment` (MTF_TREND_ALIGN, MTF_MOMENTUM_ALIGN, MTF_REGIME_1D + per-timeframe components). 21 tests incl. same-day daily-close leakage and 15m truncation invariance; ~0.6 s per asset on real data
- 2026-10-17 050-confluence: added `confluence.py` and `config/scoring_weights.py`. 30 documented signal rules in [-1, 1] are averaged within 7 families (trend/momentum/volatility/volume/pattern/sr/mtf) and weighted per regime, blended by REGIME_CONFIDENCE. Outputs TECH_SCORE, TECH_SCORE_<FAMILY> and TECH_REASONS. An explicit column→family contract covers every upstream column, and indecision candle patterns are excluded. 43 tests, including direction fixtures and truncation invariance.
- 2026-10-17 060-scorer: added `scorer.py` (`score(ticker, timeframe, as_of)`, `score_universe`) with fixed-lookback as_of loading for backtests, a `technical_scores` table, input-hash caching and `python main.py score [TICKER]`
- 2026-10-18 110-transaction-costs-lots: added `investbot/trading/` tax_rules (regime params, FY, calendar-month holding period), transaction_costs (STT/stamp/exchange/SEBI/brokerage/GST, crypto TDS) and lot_tracker (FIFO realisations, unrealised_by_lot); 40 tests; FIFO-vs-plan and holding-period decisions logged
- 2026-10-18 120-tax-ledger: added `trading/tax_ledger.py` (FY set-off, ₹1L/₹1.25L exemption, 8-year carry-forward, cess/surcharge, crypto 115BBH, `incremental_tax`), dated equity regimes with `regime_for`, and a seed that updates existing regime rows
