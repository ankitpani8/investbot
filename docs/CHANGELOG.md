- 2026-10-17 010-candle-patterns: added `candle_patterns.py`: all 61 TA-Lib CDL* patterns as raw `CDL_*` and normalised `CDLN_*` columns plus `CDL_BULL_COUNT`/`CDL_BEAR_COUNT`/`CDL_NET_SCORE` (warmup NaN, no-lookahead tests). Not wired into `add_all_indicators`

- 2026-10-17 020-support-resistance: added `support_resistance.py` (swing pivots emitted only at the confirmation bar, pivot-clustered S/R levels with touch/recency strength, rolling 70% volume profile POC/VAH/VAL/POS, Fibonacci retracements of the latest confirmed swing). 25 columns, truncation-invariance tests over all of them, ~0.3 s per 1500-row asset.
- 2026-10-17 040-multi-timeframe: added `multi_timeframe.py`: `resample_ohlcv` (NSE-session-anchored bins labelled by close time, partial 15:30 bar), `align_higher_timeframe` (only closed HTF bars; daily values from the previous session), `mtf_alignment` (MTF_TREND_ALIGN, MTF_MOMENTUM_ALIGN, MTF_REGIME_1D + per-timeframe components). 21 tests incl. same-day daily-close leakage and 15m truncation invariance; ~0.6 s per asset on real data

Outputs TECH_SCORE, TECH_SCORE_<FAMILY> and TECH_REASONS. An explicit column→family contract covers every upstream column, and indecision candle patterns are excluded. 43 tests, including direction fixtures and truncation invariance.
- 2026-10-17 060-scorer: added `scorer.py` (`score(ticker, timeframe, as_of)`, `score_universe`) with fixed-lookback as_of loading for backtests, a `technical_scores` table, input-hash caching and `python main.py score [TICKER]`
